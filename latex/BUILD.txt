LaTeX report build instructions
================================

Requirements:
- TeX Live with XeLaTeX, LaTeX base/recommended/extra packages
- DejaVu fonts
- BibLaTeX and Biber
- GNU Make (optional, but recommended)

Build the PDF:
  cd latex
  make

The Makefile runs XeLaTeX, Biber, and XeLaTeX twice more to resolve
Unicode text, citations, bibliography entries, cross-references, and
the table of contents.

Equivalent commands:
  xelatex -interaction=nonstopmode -halt-on-error report.tex
  biber report
  xelatex -interaction=nonstopmode -halt-on-error report.tex
  xelatex -interaction=nonstopmode -halt-on-error report.tex

The bibliography is managed by BibLaTeX and Biber. All cited works are
defined in references.bib and rendered by the bibliography command in
report.tex. Do not run BibTeX for this document.

The appendices load the C++ examples from ../src. Keep that directory
structure when compiling.

The generated PDF is latex/report.pdf. Remove auxiliary files with:
  make clean
